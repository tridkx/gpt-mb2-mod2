# PVP / PVE 双版本

分别打开 `model_PVP.fbx` 或 `model_PVE.fbx`。OBJ 对应同名 MTL。两版共用本目录 `tex/`，复制时一起保留。

直接替换现有 FBX 中的贴图路径，没有重新导出几何、UV、材质槽或材质参数。原 `model.fbx` 保留。材质内部名称可能仍含基线版本字样，实际使用的图像以路径为准。两版沿用本套原有未解决部件。
