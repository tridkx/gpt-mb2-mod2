# 更新记录

## v0.1.5 — 2026-10-12

- 用户反馈 v0.1.4 物品栏仍双手背后；此前日志在物品栏两次扫描均为 `visuals=0`，没有实际人物姿态证据。检查发现屏幕反射扫描可提前耗尽共享对象额度，人物的纹理提供器未被访问。
- 优先通过 CharacterTableauTextureProvider 读取明确的人物预览，使用独立扫描预算。正确骨架也需核对动作集，诊断记录实际动作名并按界面分配采样额度；保留地图/战场和未知 owner 排除条件。
- 模型、完整 TPAC、纹理、布料和碰撞体及注册动作 XML 与 v0.1.4 交付包逐文件一致，编译与入口/范围回归通过。物品栏姿态与退出物品栏回地图仍待用户游戏复测，不能据离线测试宣称修复通过。
- 已安装技能补充明确的物品栏预览入口及通用布料分层验收：完整保护面覆盖、固定根与活动余量、最终包结构、动作筛查和游戏动态分别检查。

## v0.1.4 — 2026-10-12

- 用户确认 v0.1.3 的手臂内收修复通过；该经验已写入已安装种族技能，并澄清装备与完整角色的绑定适配区别。
- 核对本机 CharacterTableau 默认 warrior 集及 AnimationClip 引用。仅覆盖本种族物品栏待机 start/loop，男女预览均使用 `anim_female_custom_start` / `anim_female_custom` 的自然垂手姿态，保留角色性别及创建页面动作；运行组件 DLL 不变。
- 安全裤保护恢复上端覆盖，局部补充 12 个腰臀碰撞体；上端随骨盆、下端随大腿，增加腰部以下裙片活动空间。安全裤高度带 0.55–0.835 米的 1,178 个表面采样点在绑定姿态全部被覆盖，原六胶囊并集有 737 点未覆盖。
- 重新检查全部 LOD、骨架、动作、布料约束与固定根；本版物品栏和安全裤效果待游戏复测，保留旧包。

## v0.1.3 — 2026-10-12

- 用户反馈创建角色、持单手武器站立时手臂过于贴近身体。检查确认此前只修改关节位置，原版绑定方向与源模型上臂相差约 18.8 度，前臂相差约 6.8 度，骨段在父骨局部侧向轴存在额外偏移。
- 对齐八根上臂、前臂及中间扭转骨的绑定方向，保留肩肘腕及掌心挂点位置、模型形状、蒙皮权重、布料配置与 UI 崩溃修复。
- 补充三种空手站立、单手与双手武器站姿扫描；利用旧版创建页面日志中 `anim_male_custom` 的实际骨骼姿态制作离线前后对照。旧日志姿态没有重现用户这次的所有穿模条件，新版效果仍待游戏复测。

## v0.1.2 — 2026-10-12

- 根据用户反馈的站立裙摆被顶起、跑动缓解，重新拟合六个腿部碰撞体的中心线与半径，保持身体表面采样覆盖，外侧余量从 3 毫米调整为 0.5 毫米。
