# 更新日志

## v0.1.3 — 2026-10-12

- 用户反馈布料使原本包裹正面的裙子聚到背后，按要求取消第二套裙子的布料模拟，全部 LOD 改为纯蒙皮。
- 清除布料标记、运行时布料数据及自有腿部布料碰撞引用；源 Blend/FBX 的活动距离归零。保留 v0.1.2 的源几何、UV、骨骼权重、固定脸和待机行为。
- 新增最终 TPAC 无布料数据检查与 v0.1.2 几何／绑定逐字节比较；旧布料报告与代理预览归入历史。较大抬腿和骑乘仍可能发生蒙皮裙片交叉，游戏表现由用户验收。

## v0.1.2 — 2026-10-12

- 根据用户反馈返修腰臀裙片离身。上段大腿胶囊不再包入整片腰臀安全裤表面，避免统一大半径撑开上部裙片。
- 腰臀改为 64 个局部姿态胶囊，以安全裤多姿态覆盖与静态裙片外推距离联合选择中心、轴向和半径；腿面余量收至 1.2 毫米。
- 保留 v0.1.1 的碰撞、覆盖、代理与预览证据，增加最终 XML 的同姿态贴合比较。源网格、UV、绑定、活动距离与布料预处理保持 v0.1.1 数据；游戏贴合效果仍由用户验收。

## v0.1.1 — 2026-10-12

- 根据用户创建角色截图返修静态安全裤露出。实际骨骼日志复算显示 v0.1.0 创建姿态有约 2.7 毫米覆盖缺口；扩大局部保护余量，并为不同姿态的腰臀过渡补充随动碰撞体。
- 安全裤覆盖检查改为最终量化权重后的姿态表面检查，独立加密三角面内部采样，包含实际创建姿态与原生动作，保留旧版失败证据。
- 上层覆盖短裙片、长裙根部及相连装饰改为本模型腰臀区域的连续随动权重，避免相接顶点使用不同权重造成拉伸；长裙活动上限收至 0.18 米，减少静止时向内收拢。保留源网格、UV、其余身体绑定、手部挂点与待机动作。
- 增加创建姿态静态重力代理和最终资源前后比较。离线检查与代理不代表游戏验收通过。

## v0.1.0 — 2026-10-12

- 第二套“沐风为裳”独立种族首版：保留原始模型、UV 和贴图，按本模型测量关节与绑定方向，生成独立资源 ID、GUID 和四级 LOD；薄上衣与裙片保留精度，避免远处皮肤穿出衣面。
- 接入第一套已验收的物品栏人物入口、引用判重和骨架／动作集修复，配置自然垂手待机及独立测试兵种。
- 两片长裙使用近处布料；保留原始部件连接，固定上缘不可参与碰撞推移。腿部与安全裤碰撞体重新拟合，保留覆盖检查、活动距离检查与最终资源预览。
- 游戏效果由用户验收，离线预览不包含引擎布料求解。
