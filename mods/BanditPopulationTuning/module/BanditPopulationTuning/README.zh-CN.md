# Bandit Population Tuning

骑砍2 v1.4.8 单人战役／故事模式的土匪数量、AI领主与定居点调节 Mod。游戏内通过 MCM 的“土匪与AI强化 / Bandit Population Tuning”页面设置，参数按存档保存；进入战役后可见。模块ID及MCM设置ID保持固定，已有土匪设置继续使用。

## 土匪数量与范围

| 参数 | 默认 | 范围 | 生效时机 |
| --- | --- | --- | --- |
| 地图队伍数量倍率 | 2 | 0.25～5 | 后续生成时的目标数量上限 |
| 每队生成人数倍率 | 2 | 0.25～5 | 后续自然生成的新队伍 |
| 生成与补充速度倍率 | 2 | 0～5 | 原版夜间按缺额补队的计算；0暂停补队 |

覆盖劫匪、海寇、山贼、森林强盗、草原强盗、沙漠强盗六类自然生成地图队伍及其各级原版兵员。逃兵、任务专用队伍、藏身处驻留／首领队、海上舰队不在范围内。不修改原版文件，不启动游戏。

队伍数量调整的是原版目标上限，实际地图数量仍受藏身处、清剿和原版夜间规则影响。每队人数在原版生成完毕后只计算一次，按总人数四舍五入、至少保留1人，使用最大余数分配保留原兵种比例。旧队不重复扩编、不即时删除。数量和人数各2倍对应约4倍的目标兵力规模，补充速度2倍只加速填补缺口；新开局初始填充比例不再乘补充速度。

可独立使用；与 Genshin Bandit Race 同时启用时，先调人数、再计算混编配额。

## AI、英雄与定居点

这些功能默认保持原版效果：所有额外增量和伤害百分比为0，AI领主带兵倍率为1。没有部队专精化和年龄设置。

- AI领主带兵上限按“原计算结果×倍率＋额外人数”调整，保留领主原有差异；AI家族队伍上限只加额外名额。
- AI领主队伍每日按每名士兵发放经验，支持遵守容量的普通／贵族新兵补充，以及按实际人数计算、限制库存天数的谷物补充。
- AI领主每周额外金钱和各项技能经验；玩家及玩家家族排除。
- 城镇／城堡的忠诚、食物、民兵、繁荣、治安、税收每日额外增量，默认仅影响非玩家家族；不调整村庄，可与村庄民兵补充Mod共同使用。
- 玩家与其他英雄的额外生命、额外伤害分别设置，普通士兵不受英雄加成影响。

完整参数、计算例子与边界集中见 [AI与定居点设置](docs/ai_settings.md)。所有参数保存后作用于后续计算，额外补兵不会立即填满队伍。原有土匪三项默认仍为2倍，独立于上述中性默认值。

## 安装与卸载

前置为现有 Harmony、ButterLib、UIExtenderEx 和 MCM v5；本机已按创意工坊 MCM v5.12.3 构建。Mod ZIP 解压到游戏 `Modules/`，启动器中放在四前置和原版单机模块之后，启用 **Bandit Population Tuning**。无需原神合集，也不需要另装一份 MCM。游戏运行中不要替换 DLL。

MCM 保存后影响后续计算。土匪三项设为1恢复原版倍率，速度设0暂停后续补队。AI增量设0、带兵倍率设1可停止额外强化。卸载后计算规则恢复，已发放的金钱、经验、粮食、士兵和已增长的聚落属性不会自动回滚；已经扩大的土匪队伍也不会自动缩小。本模块不定义新兵种或自定义存档类型；MCM设置由其原有存档行为保存，谷物小数余量由战役行为保存为普通字符串。现有存档升级、卸载后读档仍需用户实测，不以离线检查代替兼容验收。

## 工程与构建

`source/Runtime/` 为运行源码，`source/Tests/` 为离线检查，`module/BanditPopulationTuning/` 为可安装模块，`reports/` 为检查报告，`dist/` 保留交付包。依赖 .NET Framework 4.7.2 开发环境、.NET SDK、Python、本机游戏 DLL 和已安装前置。

在工作区根运行：

```powershell
python mods/BanditPopulationTuning/tools/release.py --install
```

不传 `--install` 只构建检查与打包。`--game-root`、`--workshop-root` 可指定游戏及创意工坊目录。安装仅写入本模块，更新前备份旧安装到 `build/install_backups/`，不改前置、存档或其他 Mod。

## 检查与限制

离线检查覆盖原有土匪筛选／人数分配与原神混编顺序，AI范围筛选、原结果上的倍率／加法、原特长因子和说明保留、真实兵员名单的逐兵经验、补兵容量、谷物库存／跨日余量、普通字符串保存、旧配置缺字段默认值，以及18个真实游戏方法的挂接／卸载。详见 检查输出（见源码包 `reports/offline_tests.txt`） 和 发布报告（见源码包 `reports/release_validation.json`）。游戏内菜单、实际每日／每周事件、英雄战斗效果、保存读档与长期数量变化待用户验收。

替换原版土匪生成行为或计算模型的其他 Mod 可能绕开入口。不要同时启用旧版AI强化3.0；它存在1.4.8过时接口并会叠加类似数值。游戏升级后需重新核对 DLL；补丁安装失败会在菜单与本模块 `ModuleData/runtime.log` 提示，失败功能组的补丁撤回，土匪与AI两组独立安装。
