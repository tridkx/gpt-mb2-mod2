# AI、英雄与定居点设置

适用 Bandit Population Tuning v1.1.0、Bannerlord v1.4.8 单人战役／故事模式。通过战役中的 MCM“土匪与AI强化”页面设置，按存档保存。下面所有强化默认关闭：增量为0、带兵倍率为1；范围和库存上限选项本身不会产生额外收益。

## AI家族与领主带兵

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| AI领主带兵上限倍率 | 1 | 0.25～5 |
| AI领主带兵上限额外人数 | 0 | 0～1000 |
| AI家族额外队伍名额 | 0 | 0～20 |

领主带兵上限为 `floor(收到的原计算结果×倍率＋额外人数)`，最少1。原版等级、家族等级、技能、特长及更早补丁参与计算，不统一覆盖为固定人数。例如原上限120，1.5倍、加20后为200；原上限80的另一领主则为140。改变的是容量，不自动补满。

家族队伍上限为 `原结果＋额外名额`；原上限2与4，额外加3后分别为5与7。不强制创建队伍。两项均排除玩家家族、土匪家族与已消亡家族；领主带兵容量只作用于正常、存活领主领导的AI领主队伍，排除玩家队、商队、驻军、民兵等。

## AI队伍每日补充

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| 每名士兵每日额外经验 | 0 | 0～10000 |
| 每日额外普通新兵 | 0 | 0～100 |
| 每日额外贵族新兵 | 0 | 0～100 |
| 每日每7人额外谷物 | 0 | 0～10，可小数 |
| 补粮库存上限（天） | 10 | 1～30，仅限制额外补粮 |

每天只执行一次。仅处理非玩家家族的正常AI领主队伍，排除解散中、领主死亡／被俘及正在发生地图战斗的队伍；跳过的日期不补发。

经验按每个兵种组的总人数计算，包括伤员：设置100，10人组加1000，30人组加3000到各自共享经验池；不按兵种组统一发100。英雄、俘虏和无升级目标的终点兵不发。经验池防止整数溢出，升级、升级费用、坐骑与AI选择仍由原版处理。当天先训练已有兵，再补入新兵，新兵从次日开始获得本功能经验。

新兵使用领主文化的普通／贵族基础兵入口，保留当前加载的自定义兵种配置。按当前带兵容量的剩余名额轮流分配，普通兵先获得第一个名额；例如只剩2个名额、两种各请求10人，实际各补1人。缺少某类文化入口时跳过该类，不补陌生文化兵。额外新兵为直接增援，不扣招募费；后续工资与消耗走原版规则。

补粮为 `实际成员总人数÷7×每7人设置值`，成员包括领主与伤员，不含俘虏。小数按队伍ID跨日累计，保存为普通字符串。库存上限以当前实际每日食物消耗×设置天数计算，已有各种食物都计入；达到上限停止额外发粮，不删除库存、不积压未发粮食。无食物消耗时不补。关闭补粮、队伍失效或达到上限会清理对应余量。

## AI领主每周补充

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| 每周额外第纳尔 | 0 | 0～100000 |
| 每周各技能额外经验 | 0 | 0～10000 |

每七天给存活、未被俘、非玩家家族的领主发放一次。排除玩家、玩家家族成员、同伴和非领主NPC。金钱防止整数溢出；技能经验分别发给18项原版技能，经过原版学习机制，不直接改技能等级。

## 城镇与城堡

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| 仅影响非玩家家族 | 开 | 开／关 |
| 每日忠诚额外增量 | 0 | 0～100 |
| 每日食物额外增量 | 0 | 0～100 |
| 每日民兵额外增量 | 0 | 0～100 |
| 每日繁荣额外增量 | 0 | 0～100 |
| 每日治安额外增量 | 0 | 0～100 |
| 每日税收额外第纳尔 | 0 | 0～10000 |

增量附加在相应原版最终计算结果上，保留原计算说明，不让已有倍率再次放大这些额外值；不是每次打开界面就直接增加存量。属性是否由城镇／城堡实际使用、库存与属性最终上限仍由原版处理。不调整村庄与村庄民兵，和 Cavalry Combat Tuning 的村庄民兵补充区分。所有者变化后按当前所属家族判断。

## 英雄战斗

| 参数 | 默认 | 范围 |
| --- | --- | --- |
| 其他英雄额外生命 | 0 | 0～5000 |
| 玩家额外生命 | 0 | 0～5000 |
| 其他英雄额外伤害（%） | 0 | 0～500 |
| 玩家额外伤害（%） | 0 | 0～500 |

其他英雄包括领主、同伴与玩家家族英雄，排除玩家主角。额外生命加在最大生命计算结果上，不立即治疗；伤害在战役实际战斗中乘以 `1＋百分比÷100`，例如20表示1.2倍。普通士兵不受影响，自动战斗不增加这一伤害倍率；自定义战斗不在本模块目标范围内。已有场景里的角色依赖后续原版属性／伤害计算刷新。

## 注意事项

- 已保存的土匪参数优先，缺少的AI参数使用上述中性默认值。恢复MCM默认预设会同时恢复原有土匪三项的2倍默认值。
- 不包含英雄年龄、部队专精化、驻军额外增长及藏身处内部人数调整。
- 更晚执行的其他补丁仍可能改变结果，完全替换原模型的Mod需兼容验证。不要同时加载旧版AI强化3.0。
- 停用额外强化不撤销已经发放的资源、士兵与经验，也不回滚过去的聚落增长。保留旧存档与旧安装包，游戏内每日／每周事件及读档由用户验收。
