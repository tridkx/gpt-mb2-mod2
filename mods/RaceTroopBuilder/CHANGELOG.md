# 更新日志

## v0.2.0 · 2026-10-11

- 原版中文名称读取、中英切换和双语搜索，CLI 返回双语字段。
- 种族固有护甲协议、按兵种覆盖、GUI 四部位配置；默认数据保留在外部依赖。
- net472 运行组件接入原版战役护甲更新且保留特长计算，附通用运行入口。
- 新增协议、导出、真实游戏 IL 补丁与 GUI 离线检查。


## v0.1.0 · 2026-10-11

- 新增 C# 共用核心、Windows WPF GUI 与 JSON CLI。
- 支持原版兵种单节点、完整升级分支和文化范围的独立种族替换。
- 支持原版物品槽位组合、多套战斗配置及原版随机规则；JSON 另支持平民套。
- 支持当前工作区默认种族发现、自选模块来源和真实资源注册入口。
- 生成纯数据 XML/XSLT Mod，自动声明外部种族依赖，不复制种族资源。
- 提供离线转换检查、交付 ZIP、安装一致性校验、旧版备份和回滚。
- 当前适配 v1.4.8；游戏内验收待用户完成。
