# 更新日志

## v0.1.3 — 2026-10-15

- 长发改为可见头发直接布料模拟，移除模拟代理与映射；原网格、UV、材质和蒙皮保留，衣裙仍为普通蒙皮。
- 各级直接预处理数据回读校验，并接入可见头发 CPU 近似动作诊断；创建页面增加只读资源日志。
- 用户确认 v0.1.2 默认丽莎、安柏可加载；头发色块在关闭布料后消失。用户随后确认 v0.1.3 头发色块已消除；不推断全部角色、场景和 LOD 已验收。

## v0.1.2 — 2026-10-15

- 将不符合 Direct3D BC 顶层尺寸要求的 1181×1181 表情贴图从源 PNG 重编为 2048×2048；原 PNG 和全部网格／UV 保留。
- 含长发布料时按 Native 引用驱动网格：代理无直接可见布料标记和身体绑定，清除三个附加开关，保留可见头发的布料标记、碰撞与全部预处理／映射数据。
- 最终资源、GPU 资源创建和代理输入回读通过；创建页面及头发实机表现待用户复测。v0.1.1 的透明材质方案未通过用户实测，保留在历史报告。

## v0.1.1 — 2026-10-15

- 修复 13 个长发布料角色的模拟代理借用脸部材质而出现单色斑块的问题，为代理添加独立全透明裁切材质。
- 保留四级可见网格、原贴图、骨架、权重、碰撞、布料预处理和映射数据，逐字节核对；布料继续启用。
- 离线预览纳入模拟代理，并校验最终解码贴图全部 mip 的透明度，补充凝光、薇斯纳的前后对比及全部受影响角色预览。
- v0.1.0 收到整体良好的用户反馈；v0.1.1 的实机头发效果待复测。旧版交付包保留。

## v0.1.0 — 2026-10-14

- 新增 21 个固定外观角色种族；保留已验收艾梅莉埃资源，组成 22 角色的单一合集模块。
- 随机采用芙宁娜荒配色，排除独立武器和杂物。13 个新角色启用有限长发布料，衣裙保持普通蒙皮。
- 各角色保留独立工程与种族 ID，合集统一安装、打包和管理；旧独立安装在迁移前完整备份。
- 资源与源文件执行离线检查，合集游戏场景验收待用户测试。
