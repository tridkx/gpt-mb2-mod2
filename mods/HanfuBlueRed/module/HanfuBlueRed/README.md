# 汉服少女 · 蓝红衣装 v1.0.2

## 安装与穿戴

将 HanfuBlueRed/ 文件夹放入游戏 Modules，在启动器启用，加载在 Native、SandBoxCore、Sandbox 后面。

配套穿戴发容与头饰（hbr_head）、蓝花上衣与宽袖（hbr_body）、红花宽裤与绣鞋（hbr_legs）。建议女性角色整套使用，手套槽留空。物品已注册为商品，并可用于平民装备。

## 当前外观与限制

包含原模型脸部、长发、蓝花上衣、红花宽裤和绣鞋，背部与后腰补面使用匹配蓝色。脸型固定，体型滑块、男性角色和混搭兼容尚未游戏验证。

游戏测试由用户完成。重点观察头颈、长发与肩袖、握持、骑乘、鞋底接地和远景切换；离线检查不代表游戏无穿模。

本文件为安装包内使用说明。可编辑工程 README 提供重建方法，工程 CHANGELOG 保存版本变化。
