# SK_BR 去脚版（脚不再穿出鞋面）

源模型 `models/08_孟柏汝_BoRu_女/SK_BR.psk` **只读使用，未做任何修改**
（时间戳仍是 2026-09-16 22:00，`git status` 干净）。本目录是另开的产物目录。

## 问题

裸体脚比帆布鞋大，脚背/脚趾从鞋头穿出来一块（见 `对比_脚部侧面.png` 左图）。

量出来的情况：身体槽 Z<25 的顶点 1078 个，其中 **167 个落在鞋壳之外**，集中在
Z 0~8（脚趾、脚背前段），正是穿模的那一块。

## 做法

只删身体槽（material_0）里 **面质心 Z < 13.5** 的面，然后把这批面残留的、
低于 13.5 的顶点统一抬到 Z=13.50，让切口平齐。13.5 这个高度取自**鞋帮外壳顶 13.83**，
所以切口整段藏在鞋口里面，外面看不到。

没有移动、没有删除、没有重算任何别的东西。

## 骨骼有没有影响？—— 骨架零改动，只是脚骨不再带动脚趾的顶点

* **骨骼表（REFSKELT）逐字节相同**：80 根骨的名字、父子关系、绑定姿态（pos/quat）全部原样，
  一根没删、一根没动。骨架仍然是完整的 80 骨骼 `SKEL_BR`。
* **保留顶点的权重原样**：21637 个带权重点的权重值和骨骼索引与原来 100% 一致，
  没有重新分配权重、没有重新归一化。
* 只有 6 根骨的**权重总量**下降（因为绑在脚上的顶点被删了）：

  | 骨骼 | 权重总量 | 变化 |
  |---|---|---|
  | `ball_l` / `ball_r`（脚掌前部） | 529.8 → 100.3 | −81% |
  | `foot_l` / `foot_r` | 403.2 → 332.5 | −18% |
  | `calf_twist_01_l` / `_r` | 233.8 → 217.0 | −7% |

* **没有任何骨头变成「零顶点驱动」**——`ball_l/ball_r` 剩下的那 100 还是绑在鞋内的
  脚踝/脚跟顶点上，`foot_l/r`、腿骨全部照常有顶点。
* 实际含义：把这套骨架接到动画上，脚骨照常做动作，只是脚趾那截皮肤不在了，
  所以不会再有东西从鞋面顶出来。对蒙皮、动画、LOD 都没有副作用。

## 想改切割高度

脚本在工作目录：`feet_cut.py`（配合 `psk_lib.py`）。

```bash
python feet_cut.py <原SK_BR.psk> <输出.psk> --z-cut 13.5
```

* 调**高** `--z-cut` → 腿留得短一些（切进鞋里更多，更保险，但小腿可能显得短）。
* 调**低** `--z-cut` → 留多一点的脚踝，但太低了脚背又会露出来。
* 加 `--probe` 只看统计不写文件。

13.5 是按「鞋帮外壳（1018 面的那个鞋分量）顶高 13.83」自动推的默认值：
不传 `--z-cut` 时脚本会取「面数最多的鞋分量顶高 − 0.3」。实测正面 / 侧面 / 背面 /
俯视都看不到切口。

工具脚本在 `tools/`（自包含，`feet_cut.py` + `psk_lib.py`；渲染核查用
`feet_check.py` / `mesh_render.py`）。
