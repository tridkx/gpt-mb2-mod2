# 更新日志

## v0.1.3 — 2026-10-10

- 增加 E 单次、F 持续写入的头骨局部矩阵诊断，头骨三轴设为参考长度 2 倍，保留局部原点及动画朝向。
- 使用 SetBoneLocalFrame 与 UpdateEntitialFramesFromLocalFrames；恢复阶段将头骨轴长度设回参考长度。
- 编译后算法检查覆盖旋转父骨转换、原点保留、1000 次无倍率累积及恢复；不代表原生引擎验证。
- 记录 v0.1.2 用户反馈及日志：C/D 未观测到头部缩放，D 重施 2278 次仍未见头骨轴长度变化。
- E/F 共用 A 网格，TPAC 与 v0.1.2 字节相同；保留旧装备与交付包，本版只有 E/F 启动诊断。

## v0.1.2 — 2026-10-10

- 新增 C 单次、D 每次显示前重施的头骨 2 倍诊断装备；两组均引用同一套 A 网格。
- 自动切换正常、放大、恢复阶段，仅作用于单机玩家角色；加入装备切换与场景结束恢复。
- 不再调用 ForceUpdateBoneFrames，补充完整骨骼矩阵及骨索引映射，避免只凭关节位置判断蒙皮缩放。
- 用户已确认 v0.1.1 A/B 在背包和战斗中可见；原预期的骨段长度变化未观测到，缩放机制继续诊断。
- 本版保持 TPAC、原始输入及源模型不变；运行效果仍需用户游戏验证。

## v0.1.1 — 2026-10-09

- 针对用户反馈 v0.1.0 的 A/B 两套穿上均不可见，将网格资源名及 XML 引用统一为小写，保留装备 ID。
- 加入引擎网格加载结果、子网格数量与延迟骨架快照，区分资源加载失败和缩放问题。
- 与 v0.1.0 最终 TPAC 比较，四级 LOD 的顶点、UV、索引、权重与材质引用未改变。
- 顶点 Alpha 全为 255，存在不透明材质；本次按疑似资源名称查找问题处理，可见性等待 v0.1.1 游戏复测。
