# 更新日志

## v1.1.0 — 2026-10-15

- 三个参数接入 MCM v5 全局菜单，中文控件；保存后在下一次战斗属性刷新时生效，无需重启。
- 首次创建 MCM 配置沿用旧 XML 初值，后续优先使用 MCM 持久化配置；保留 XML 回退。
- 依赖现有四前置，移除本模块自带 Harmony DLL。升级前备份旧安装，保留旧交付包与用户配置。
- 增加 MCM 定义、保存事件、配置快照和事件解绑的离线回归；菜单与持久化实机验收待用户确认。

## v1.0.0 — 2026-10-15

- 新增独立单机模块，冲撞基础伤害默认 2.5 倍。
- 骑乘弓弩移动精度惩罚默认降低 30%，玩家与双方 AI 一致；支持仅 AI 设置。
- 新增 XML 数值配置、配置校验与运行日志，接入战役及自定义战斗属性更新。
- 提供离线回归、独立构建／打包／安装工具与源码交付；实机验收由用户完成。
