# 更新日志

## v1.2.1 — 2026-10-15

- 根据用户启动日志修复初始菜单“补丁加载失败”：旧代码在 `OnSubModuleLoad` 中按短名称 `Assembly.Load("SandBox")` 无法绑定游戏模块加载上下文。
- 改在模块加载完成后的初始菜单阶段安装，直接复用已加载 SandBox 程序集；保留无初始菜单宿主的任务初始化回退，并避免重复挂接。
- 离线回归覆盖 Sandbox 尚未加载的启动阶段、后续加载后的实际挂接和重复初始化；实机主菜单复测待用户确认。保留所有用户配置。

## v1.2.0 — 2026-10-15

- 新增村庄民兵 MCM 分组：正向补充倍率、每日额外人数、仅玩家家族范围，默认2倍／0／全部村庄。
- 仅调整正常村庄基础与炉灶补充，保留退休率、民兵兵种、城镇／城堡及非正常状态规则；提示中显示补充差额。
- 保持既有战斗设置和全局配置ID，旧配置缺失的新字段使用默认值；无需新档。
- 离线回归增加每日增长、退休分离、状态／归属、配置兼容和保存后生效检查；实机每日增长待用户验收。

## v1.1.0 — 2026-10-15

- 三个参数接入 MCM v5 全局菜单，中文控件；保存后在下一次战斗属性刷新时生效，无需重启。
- 首次创建 MCM 配置沿用旧 XML 初值，后续优先使用 MCM 持久化配置；保留 XML 回退。
- 依赖现有四前置，移除本模块自带 Harmony DLL。升级前备份旧安装，保留旧交付包与用户配置。
- 增加 MCM 定义、保存事件、配置快照和事件解绑的离线回归；菜单与持久化实机验收待用户确认。

## v1.0.0 — 2026-10-15

- 新增独立单机模块，冲撞基础伤害默认 2.5 倍。
- 骑乘弓弩移动精度惩罚默认降低 30%，玩家与双方 AI 一致；支持仅 AI 设置。
- 新增 XML 数值配置、配置校验与运行日志，接入战役及自定义战斗属性更新。
- 提供离线回归、独立构建／打包／安装工具与源码交付；实机验收由用户完成。
